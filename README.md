# Custom Wazuh Rules, Active Response, and Telegram Integration

A collection of custom scripts and configurations for extending Wazuh detection, alerting, and automated response capabilities.
This repository contains custom Wazuh rules, Active Response scripts, and Telegram integrations developed to detect suspicious activities and automatically respond to security events.

# How to Use
## Command to download all Script

```bash
# git clone https://github.com/ynonrp/custom-wazuh.git
```
## Wazuh telegram integration
Copying integration script
```bash
# cp custom-wazuh/TelegramIntegration/* /var/ossec/integrations/
```
